# Project-Rando

## Resonance Bastion · player-experience edition

[Play the game directly](https://thomasgross83420-a11y.github.io/Project-Rando/?build=0.4.0-player-experience)

[Read the review](https://thomasgross83420-a11y.github.io/Project-Rando/review/player-experience.html) · [Download the review file](https://thomasgross83420-a11y.github.io/Project-Rando/review/player-experience.md)

Open in your usual Chrome profile, create or continue a Bastion, then choose **Next siege → Start siege** after the short briefing. Defenders fight automatically. Drag empty field space to pan, pinch to zoom, and tap assets to inspect them. Build previews spend nothing until Place succeeds. Menus close to reveal the field.

Build **0.4.0-player-experience** improves touch navigation, guidance, movement/facing, formation and siege recovery, restoration quotes, backup handling and collision performance. It retains the full roster, campaign, additional modes and existing full-version save schema.

Verification includes 189 unit/integration tests, 90 distinct browser cases and a repeated 63-case combat sweep. Regression defeats are not campaign clears. Physical Lenovo performance, long-term natural balance and further asset refinement remain open; the review states the evidence and provisional design ratings.

Progress stays in this browser on this site. **Manage → Data / backups → Export backup** offers sharing or download. First load and uncached resources need internet. Earlier preview saves remain separate and can be explicitly imported.
